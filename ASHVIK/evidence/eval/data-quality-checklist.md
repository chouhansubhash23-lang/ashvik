# Data Quality Checklist

Use this checklist for every condition file in `../../data/guidelines/`.

## 1. Source and traceability
- [ ] Primary national source cited (ICMR / NCDC / NVBDCP / NTEP / NPCDCS)
- [ ] Source URL works and is publicly accessible
- [ ] Retrieval date recorded
- [ ] Page/section reference recorded where possible

## 2. Clinical accuracy
- [ ] Case definition / clinical features match the source
- [ ] Danger signs and red flags are explicitly listed
- [ ] Diagnosis tests are available at PHC/CHC level or referral is stated
- [ ] Treatment matches the national first-line recommendation
- [ ] Adult and paediatric doses are separated
- [ ] Renal/hepatic dose adjustment noted where relevant
- [ ] Pregnancy/lactation contraindications noted

## 3. Drug information
- [ ] Generic name given first
- [ ] Brand example labelled "illustrative"
- [ ] Dose, route, frequency, duration all present
- [ ] Maximum daily dose stated
- [ ] Key interactions listed
- [ ] Key cautions/contraindications listed
- [ ] No promotional language

## 4. Safety
- [ ] Disclaimer present
- [ ] "Refer immediately" criteria present
- [ ] No advice that delays emergency care
- [ ] No unapproved/experimental therapy presented as standard

## 5. Review
- [ ] Reviewed by a clinician (name/date)
- [ ] Cross-checked against a second source
- [ ] Version and change note recorded
