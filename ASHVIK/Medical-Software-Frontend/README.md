# ASHVIK - Clinical Consultation & Treatment Frontend

Single-file medical software frontend for diagnosing patients and prescribing treatment.

## Features
- Dashboard with patient/consultation counts and recent consultations
- New Consultation: patient + vitals, symptom chips, diagnosis with disease templates, prescription (medicines table), advice, tests, follow-up, referral
- Patients: add/edit/delete, search
- History & Rx: view all consultations, reprint prescription
- Data saved in browser localStorage

## Common disease templates (auto-fill Rx)
Viral fever, Malaria, Dengue, Typhoid, Acute diarrhoea, Hypertension, Type 2 Diabetes, Asthma, COPD, UTI, Scabies, Fungal skin infection, Iron deficiency anaemia, Hypothyroidism, Acute bronchitis, Allergic rhinitis.

## How to use
1. Open `index.html` in a modern browser.
2. Add a patient in Patients tab.
3. Go to New Consultation, select patient, pick symptoms/disease template, edit Rx, Save and Print.

## Disclaimer
Templates are generic educational suggestions, not patient-specific medical advice. Always use clinical judgment.
