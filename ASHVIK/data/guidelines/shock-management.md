# Shock Management

> **Source:** ICMR; WHO; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Shock = inadequate tissue perfusion.
- Types: hypovolaemic, septic, cardiogenic, obstructive, anaphylactic.
- ABCDE and rapid fluids/vasopressors.
- Refer early.

## 2. Clinical features

- Hypotension, tachycardia
- Cold clammy skin
- Altered consciousness
- Oliguria
- Delayed capillary refill
- Metabolic acidosis

## 3. Diagnosis / Assessment

| Type | Clues |
|---|---|
| Hypovolaemic | Bleeding, diarrhoea, dehydration |
| Septic | Fever, source |
| Cardiogenic | Chest pain, JVP raised, crackles |
| Obstructive | Tamponade, tension pneumothorax |
| Anaphylactic | Urticaria, angioedema |

## 4. Treatment

| Type | Treatment |
|---|---|
| Hypovolaemic | IV fluids/blood |
| Septic | Fluids + antibiotics |
| Cardiogenic | Diuretics, inotropes (specialist) |
| Obstructive | Relieve cause |
| Anaphylactic | Adrenaline 0.5 mg IM |

**Fluids:** 500–1000 mL crystalloid bolus; reassess.
**Noradrenaline** if MAP < 65 despite fluids.

**Brand examples (illustrative):** Adrenaline; Noradrenaline; Monocef.

## 5. Supportive care

- Oxygen
- Monitor urine output
- Warm
- Refer

## 6. Drug interactions and cautions

- **Vasopressors:** extravasation, arrhythmia.
- **Fluids:** overload.
- **Adrenaline:** tachycardia.
- **Sedatives:** hypotension.

## 7. Red flags — refer immediately

- Persistent hypotension
- Altered consciousness
- Oliguria
- Lactate > 4
- Ongoing bleeding

## 8. Follow-up

- Reassess perfusion.
- Treat cause.
- ICU referral.
