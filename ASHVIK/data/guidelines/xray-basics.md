# Chest X-ray Interpretation Basics

> **Source:** ICMR STW Vol. 3 (2022); WHO; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Chest X-ray is essential for pneumonia, TB, effusion, pneumothorax, heart failure.
- Use a systematic approach (ABCDE).
- Compare with previous films.
- Always interpret with clinical findings.

## 2. Systematic reading (ABCDE)

| Step | Check |
|---|---|
| A | Airway/trachea position |
| B | Bones/soft tissue |
| C | Cardiac silhouette |
| D | Diaphragm |
| E | Effusion/fields/lungs |

## 3. Common patterns

| Pattern | Features |
|---|---|
| Pneumonia | Consolidation, air bronchograms |
| TB | Upper lobe infiltrates, cavitation |
| Pleural effusion | Blunted costophrenic angle, meniscus |
| Pneumothorax | Visible pleural line, absent markings |
| Heart failure | Cardiomegaly, pulmonary oedema |
| COPD | Hyperinflation, flat diaphragm |
| Fracture | Rib fracture |

## 4. Diagnosis / Assessment

- PA view preferred; lateral if needed.
- Inspiratory effort (9–10 posterior ribs).
- Rotation (clavicles symmetrical).
- Penetration (vertebrae visible behind heart).

## 5. Treatment implications

| Finding | Action |
|---|---|
| Consolidation | Antibiotics, follow-up |
| Effusion | Ultrasound/thoracentesis if large |
| Pneumothorax | Oxygen, needle decompression if tension |
| TB | Sputum/CBNAAT, DOTS |
| Heart failure | Diuretics, refer |

**Brand examples (illustrative):** Amoxicillin — Mox; Furosemide — Lasix.

## 6. Drug interactions and cautions

- Contrast media can cause allergic reactions and kidney injury.
- Sedatives may be needed in children — monitor breathing.
- Diuretics can worsen dehydration.

## 7. Supportive care

- Oxygen if hypoxic
- Paracetamol 500 mg for pain/fever
- Treat cause
- Repeat X-ray as indicated

## 8. Red flags — refer immediately

- Tension pneumothorax
- Massive effusion
- Widened mediastinum
- Free air under diaphragm
- Suspected malignancy
- Severe pneumonia

## 9. Follow-up

- Repeat after treatment.
- Compare with old films.
- Refer if unresolved.
