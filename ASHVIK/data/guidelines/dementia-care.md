> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Dementia is progressive cognitive decline affecting daily life.
- Alzheimer's is the commonest cause.
- Assess reversible causes (thyroid, B12, depression, drugs).
- Support the caregiver.

## 2. Clinical features

- Memory loss
- Disorientation
- Language difficulty
- Behavioural changes
- Difficulty with daily activities
- Wandering, aggression

## 3. Diagnosis / Assessment

| Test | Use |
|---|---|
| Cognitive screen (MMSE/MOCA) | Severity |
| TSH, B12, CBC | Reversible causes |
| Depression screen | Pseudodementia |
| Medication review | Anticholinergics |
| Imaging | Atrophy/vascular |

## 4. Treatment

| Measure | Detail |
|---|---|
| Cholinesterase inhibitor | Donepezil 5–10 mg HS (mild-moderate) |
| Memantine | Moderate-severe (specialist) |
| Behavioural | Routine, safety, stimulation |
| Caregiver support | Essential |

**Brand examples (illustrative):** Donepezil — Donep; Memantine — Admenta; Paracetamol 500 mg for pain.

## 5. Supportive care

- Safe environment
- Routine and orientation
- Day care
- Legal/financial planning

## 6. Drug interactions and cautions

- **Donepezil:** bradycardia, GI upset; caution in asthma/ulcer.
- **Anticholinergics:** worsen cognition — avoid.
- **Sedatives:** falls, confusion.
- **Memantine:** dizziness.

## 7. Red flags — refer immediately

- Sudden worsening (delirium)
- New focal deficit
- Seizures
- Aggression/self-harm
- Caregiver crisis

## 8. Follow-up

- Regular cognitive/functional review.
- Caregiver support.
- Safety assessment.
