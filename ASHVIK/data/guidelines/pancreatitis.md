# Acute Pancreatitis

> **Source:** ICMR STW Vol. 3 (2022); IAP/APA; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-27
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Causes: gallstones, alcohol, hypertriglyceridaemia, drugs, infections.
- Severe epigastric pain radiating to back with vomiting.
- **Refer early** — severe pancreatitis has high mortality.
- Avoid alcohol and unnecessary drugs.

## 2. Clinical features

- Severe epigastric pain radiating to back
- Vomiting, nausea
- Abdominal tenderness, distension
- Fever, tachycardia
- Shock in severe cases
- Cullen's/Grey Turner's signs (late, severe)

## 3. Diagnosis

| Test | Use |
|---|---|
| Serum amylase/lipase | > 3x upper limit |
| CBC, CRP | Severity/inflammation |
| LFT, calcium, triglycerides | Cause/severity |
| Ultrasound | Gallstones |
| CT (after 72 h) | Necrosis (if available) |

## 4. Treatment

| Measure | Detail |
|---|---|
| Nil by mouth | Initially; early enteral feeding when tolerated |
| IV fluids | Aggressive 0.9% saline/Ringer's lactate |
| Analgesia | Paracetamol 500 mg IV; opioid if severe |
| Antiemetics | Ondansetron |
| Antibiotics | Not routine; only for infected necrosis |
| Referral | Severe pain, organ failure, gallstone pancreatitis |

**Brand examples (illustrative):** Paracetamol — Dolo 650; Ondansetron — Emeset.

## 5. Supportive care

- Monitor vitals, urine output
- Correct electrolytes
- Oxygen if hypoxic
- Treat cause (ERCP for gallstone obstruction)
- Nutrition support

## 6. Drug interactions and cautions

- **Opioids:** may cause sphincter spasm; use judiciously.
- **NSAIDs:** avoid in kidney injury.
- **Antibiotics:** not routine; if used, renal adjustment.
- **Alcohol:** absolute avoidance.

## 7. Red flags — refer immediately

- Organ failure (respiratory, renal, cardiovascular)
- Shock
- Severe pain not controlled
- Infected necrosis
- Gallstone pancreatitis with cholangitis
- Pregnancy with pancreatitis
- Rising creatinine/oliguria

## 8. Follow-up

- Repeat amylase/lipase, CBC.
- Ultrasound for gallstones.
- Alcohol counselling.
- Surgical review for cholecystectomy if gallstones.
