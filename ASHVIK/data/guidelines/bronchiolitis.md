# Bronchiolitis

> **Source:** ICMR STW Vol. 3 (2022); WHO/IMNCI; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Viral lower respiratory infection, usually < 2 years (RSV).
- Most cases are self-limiting; treatment is supportive.
- **No routine antibiotics, bronchodilators, or steroids.**
- Refer if respiratory distress or hypoxia.

## 2. Clinical features

- Runny nose, cough, low-grade fever
- Fast breathing, wheeze, crackles
- Chest indrawing, nasal flaring
- Poor feeding
- Apnoea in infants

## 3. Diagnosis / Assessment

| Sign | Severity |
|---|---|
| Feeding well, SpO2 ≥ 92% | Mild — home care |
| Chest indrawing, SpO2 < 92% | Severe — refer |
| Apnoea/cyanosis | Critical — refer |

- Chest X-ray only if complications suspected.
- Pulse oximetry essential.

## 4. Treatment

| Measure | Detail |
|---|---|
| Oxygen | If SpO2 < 92% |
| Hydration | Breastfeed/ORS; NG if needed |
| Nasal suction | Saline drops |
| Paracetamol | 15 mg/kg/dose for fever |
| Antibiotics | Only if bacterial co-infection |

**Brand examples (illustrative):** Paracetamol — Calpol; Saline nasal drops.

**Do not routinely use** salbutamol, steroids, or antibiotics.

## 5. Supportive care

- Position upright
- Small frequent feeds
- Monitor breathing and SpO2
- Hand hygiene

## 6. Drug interactions and cautions

- **Paracetamol:** max 4 doses/day.
- **Antibiotics:** unnecessary; resistance.
- **Bronchodilators:** not recommended routinely.
- **Steroids:** not recommended.

## 7. Red flags — refer immediately

- SpO2 < 92%
- Severe chest indrawing
- Apnoea
- Cyanosis
- Poor feeding/dehydration
- Lethargy
- Age < 3 months

## 8. Follow-up

- Review in 24–48 h.
- Return if worsening.
- Educate parents on danger signs.
