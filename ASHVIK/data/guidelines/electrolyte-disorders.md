# Electrolyte Disorders (Na, K, Ca)

> **Source:** ICMR; WHO; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Correct slowly; rapid correction can be dangerous.
- Check glucose, renal function, and medications.
- Severe abnormalities need monitored correction/referral.
- Treat the cause.

## 2. Clinical features

| Disorder | Features |
|---|---|
| Hyponatraemia | Confusion, seizures, coma |
| Hypernatraemia | Thirst, confusion, seizures |
| Hypokalaemia | Weakness, arrhythmia, cramps |
| Hyperkalaemia | Weakness, arrhythmia, cardiac arrest |
| Hypocalcaemia | Tetany, cramps, seizures |
| Hypercalcaemia | Stones, bones, confusion, constipation |

## 3. Diagnosis / Assessment

| Test | Use |
|---|---|
| Serum Na/K/Ca | Confirm |
| ECG | Hyper/hypokalaemia |
| Renal function | Cause |
| Glucose | Pseudohyponatraemia |
| Medications | Diuretics, ACEi |

## 4. Treatment

| Disorder | Treatment |
|---|---|
| Hyponatraemia | Slow correction (≤ 8–10 mmol/L/day); 3% saline if seizures |
| Hypernatraemia | Slow free-water deficit correction |
| Hypokalaemia | Oral/IV KCl (max 10–20 mmol/h peripheral) |
| Hyperkalaemia | Calcium gluconate 10 mL 10%, insulin-dextrose, salbutamol |
| Hypocalcaemia | Calcium gluconate 10 mL 10% IV |
| Hypercalcaemia | IV fluids, refer |

**Brand examples (illustrative):** KCl; Calcium gluconate; Salbutamol — Asthalin.

## 5. Supportive care

- Monitor ECG/vitals
- Treat cause
- Avoid rapid correction

## 6. Drug interactions and cautions

- **Potassium:** never IV bolus.
- **Calcium:** extravasation injury.
- **Diuretics:** electrolyte loss.
- **ACEi/ARB:** hyperkalaemia.

## 7. Red flags — refer immediately

- Seizures/coma
- K+ > 6.5 or < 2.5
- Na+ < 120 or > 155
- Arrhythmia
- Renal failure

## 8. Follow-up

- Repeat electrolytes.
- Review medications.
- Treat cause.
