# Oxygen Therapy

> **Source:** ICMR STW Vol. 3 (2022); WHO; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Oxygen is a drug; prescribe a target SpO2.
- Target SpO2 94–98% for most adults; 88–92% in COPD.
- Use the lowest flow to achieve target.
- Monitor for oxygen toxicity and CO2 retention.

## 2. Indications

- SpO2 < 94% (or < 90% in COPD)
- Breathlessness with hypoxia
- Shock/sepsis
- Cardiac/respiratory arrest
- Carbon monoxide poisoning

## 3. Diagnosis / Assessment

| Assessment | Detail |
|---|---|
| SpO2 | Pulse oximeter |
| Respiratory rate | Tachypnoea |
| ABG | If available |
| Conscious level | Confusion |
| COPD history | Target 88–92% |

## 4. Treatment: delivery devices

| Device | Flow | FiO2 |
|---|---|---|
| Nasal cannula | 1–6 L/min | 24–44% |
| Simple mask | 5–10 L/min | 35–55% |
| Venturi mask | Variable | 24–60% |
| Non-rebreather | 10–15 L/min | 80–95% |
| Bag-valve-mask | 15 L/min | ~100% |

**Humidification** for high-flow/prolonged use.

## 5. Supportive care

- Position upright
- Paracetamol 500 mg for associated pain/fever
- Treat cause (asthma, pneumonia, heart failure)
- Monitor SpO2 and RR
- Keep oxygen source safe (no smoking)

## 6. Drug interactions and cautions

- **COPD:** high-flow oxygen may cause CO2 retention — target 88–92%.
- **Oxygen toxicity:** prolonged high FiO2.
- **Fire risk:** no smoking/flames.
- **Nebulisation:** oxygen-driven if available.

## 7. Red flags — refer immediately

- SpO2 < 90% despite oxygen
- Worsening breathlessness
- Confusion/drowsiness
- Cyanosis
- Respiratory failure

## 8. Follow-up

- Reassess need frequently.
- Wean oxygen when stable.
- Document target and device.
