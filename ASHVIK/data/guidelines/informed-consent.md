# Informed Consent

> **Source:** NMC/MCI guidelines; ICMR; WHO
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Consent must be **informed, voluntary, and documented**.
- Explain diagnosis, options, risks, benefits, and alternatives.
- Use language the patient understands.
- Emergency treatment can proceed without consent if life-threatening.

## 2. Diagnosis / Assessment

- Check patient capacity.
- Identify language/literacy needs.
- Determine need for guardian consent (minor, incapacitated).
- Document discussion.

## 3. Treatment: consent process

| Step | Detail |
|---|---|
| 1 | Explain condition |
| 2 | Explain procedure/treatment |
| 3 | Discuss risks/benefits/alternatives |
| 4 | Answer questions |
| 5 | Obtain written consent |
| 6 | Document |

- Use **paracetamol 500 mg** example for explaining a simple prescription.
- For procedures, use procedure-specific consent form.

## 4. Drug interactions and cautions

- **Dose:** not applicable (non-drug topic).
- **Coercion:** invalidates consent.
- **Language:** use interpreter if needed.
- **Minors:** guardian consent; assent where possible.

## 5. Supportive care

- Provide written information.
- Allow time to decide.
- Respect refusal.
- Maintain confidentiality.

## 6. Red flags

- No consent for procedure
- Consent obtained under coercion
- Patient lacks capacity without guardian
- Language barrier ignored
- Consent form unsigned

## 7. Follow-up

- Document consent in record.
- Review if condition changes.
- Audit consent forms.
