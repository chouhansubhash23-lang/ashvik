# Delirium

> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Delirium is acute, fluctuating confusion — a medical emergency.
- Common in older adults with infection, dehydration, drugs, or surgery.
- **Find and treat the cause.**
- Avoid restraints and sedatives.

## 2. Clinical features

- Acute onset, fluctuating course
- Inattention
- Disorientation
- Hallucinations
- Agitation or withdrawal
- Sleep disturbance

## 3. Diagnosis / Assessment

| Test | Use |
|---|---|
| 4AT/CAM | Screening |
| Vitals, SpO2 | Hypoxia/infection |
| Glucose, electrolytes | Metabolic cause |
| Urine, chest | Infection |
| Medication review | Drug-induced |

## 4. Treatment

| Cause | Action |
|---|---|
| Infection | Antibiotics |
| Dehydration | Fluids |
| Drug-induced | Stop offending drug |
| Pain | Paracetamol 500 mg |
| Hypoxia | Oxygen |

- Reorient and involve family.
- Avoid antipsychotics unless severe agitation/psychosis (haloperidol 0.5 mg).

**Brand examples (illustrative):** Paracetamol — Dolo 650; Haloperidol — Serenace.

## 5. Supportive care

- Safe environment
- Sleep hygiene
- Glasses/hearing aids
- Mobilisation

## 6. Drug interactions and cautions

- **Anticholinergics:** worsen delirium.
- **Benzodiazepines:** avoid (except withdrawal).
- **Opioids:** monitor.
- **Antipsychotics:** QT, extrapyramidal.

## 7. Red flags — refer immediately

- Hypoxia
- Sepsis
- Head injury
- Stroke
- Alcohol withdrawal
- Severe agitation

## 8. Follow-up

- Reassess cognition.
- Prevent recurrence.
- Caregiver education.
