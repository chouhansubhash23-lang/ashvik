# Childhood Asthma

> **Source:** ICMR STW Vol. 3 (2022); GINA; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Asthma is common in children; often allergic.
- Use a spacer with inhalers.
- **Inhaled corticosteroid is the controller.**
- Severe exacerbation needs oxygen and referral.

## 2. Clinical features

- Recurrent wheeze, cough (night/early morning)
- Breathlessness
- Chest tightness
- Triggers: dust, smoke, pollen, exercise, cold
- Poor response to bronchodilator in severe cases

## 3. Diagnosis / Assessment

| Test | Use |
|---|---|
| Clinical history | Recurrent wheeze/triggers |
| Spirometry | If age > 5 |
| Peak flow | Monitoring |
| SpO2 | Severity |
| Allergy history | Triggers |

## 4. Treatment

| Step | Treatment |
|---|---|
| Reliever | Salbutamol 100 mcg 2 puffs via spacer as needed |
| Controller | Budesonide 100–200 mcg BD via spacer |
| Severe exacerbation | Salbutamol nebs + prednisolone 1–2 mg/kg/day x 3–5 days |

**Brand examples (illustrative):** Asthalin; Budecort; Wysolone.

- Use spacer for all children.
- Review inhaler technique.

## 5. Supportive care

- Avoid triggers
- Annual influenza vaccine
- Written action plan
- Parent education

## 6. Drug interactions and cautions

- **Beta-blockers:** avoid.
- **Salbutamol:** tremor, tachycardia.
- **Steroids:** short course; monitor.
- **Inhaled steroids:** rinse mouth.

## 7. Red flags — refer immediately

- SpO2 < 92%
- Unable to speak/feed
- Silent chest
- Cyanosis
- Altered consciousness
- No response to reliever

## 8. Follow-up

- Review every 1–3 months.
- Step up/down as per control.
- Spirometry yearly if available.
