# Substance Use Disorders (Opioids, Cannabis, Stimulants)

> **Source:** WHO; ICMR; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Substance use is a health condition, not a moral failure.
- Screen non-judgmentally; offer harm reduction.
- Opioid overdose is an emergency — naloxone.
- Refer for de-addiction and psychosocial support.

## 2. Clinical features

| Substance | Features |
|---|---|
| Opioids | Pinpoint pupils, sedation, respiratory depression |
| Cannabis | Anxiety, paranoia, memory problems |
| Stimulants | Agitation, palpitations, insomnia, psychosis |
| Injecting drug use | Abscesses, HIV/HCV risk |

## 3. Diagnosis / Assessment

| Assessment | Detail |
|---|---|
| Substance history | Type, amount, route |
| Withdrawal | Timeline, severity |
| Mental health | Depression/psychosis |
| Infections | HIV/HCV/TB |
| Social | Family, legal |

## 4. Treatment

| Situation | Treatment |
|---|---|
| Opioid overdose | Naloxone 0.4 mg IV/IM, repeat |
| Opioid withdrawal | Buprenorphine 2–8 mg (specialist) |
| Opioid dependence | Methadone/buprenorphine (OST) |
| Stimulant intoxication | Benzodiazepines, supportive |
| Counselling | Motivational interviewing |

**Brand examples (illustrative):** Naloxone; Buprenorphine — Subutex.

## 5. Supportive care

- Harm reduction (needle exchange)
- HIV/HCV testing
- Mental health support
- Social rehabilitation

## 6. Drug interactions and cautions

- **Naloxone:** precipitates withdrawal.
- **Buprenorphine:** respiratory depression; specialist.
- **Benzodiazepines + opioids:** fatal respiratory depression.
- **Paracetamol 500 mg** for pain.

## 7. Red flags — refer immediately

- Respiratory depression
- Overdose
- Psychosis/agitation
- Suicidal ideation
- Infective endocarditis
- Seizures

## 8. Follow-up

- De-addiction program
- Relapse prevention
- Infection screening
