# Alcohol Use Disorder

> **Source:** WHO; ICMR; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Screen with AUDIT-C.
- Withdrawal can be life-threatening — treat with benzodiazepines and thiamine.
- Brief intervention helps.
- Refer for de-addiction.

## 2. Clinical features

- Craving, loss of control
- Withdrawal: tremor, sweating, seizures, delirium tremens
- Liver disease, pancreatitis
- Neuropathy, memory loss
- Social/family problems

## 3. Diagnosis / Assessment

| Test | Use |
|---|---|
| AUDIT | Screening |
| LFT, MCV | Chronic use |
| Glucose, electrolytes | Withdrawal |
| CIWA | Withdrawal severity |
| Mental health | Depression/suicide |

## 4. Treatment

| Situation | Treatment |
|---|---|
| Withdrawal | Chlordiazepoxide 10–25 mg q6h (taper) |
| Delirium tremens | Benzodiazepines + refer |
| Thiamine deficiency | Thiamine 100 mg IV/IM daily |
| Maintenance | Naltrexone/Acamprosate (specialist) |
| Counselling | Brief intervention |

**Brand examples (illustrative):** Chlordiazepoxide — Librium; Thiamine; Naltrexone — Naltima.

## 5. Supportive care

- Hydration
- Nutrition
- Thiamine before glucose
- Family support

## 6. Drug interactions and cautions

- **Benzodiazepines:** respiratory depression.
- **Disulfiram:** hepatotoxicity, reaction with alcohol.
- **Naltrexone:** hepatotoxicity.
- **Paracetamol:** hepatotoxicity in liver disease.

## 7. Red flags — refer immediately

- Delirium tremens
- Seizures
- GI bleeding
- Pancreatitis
- Suicidal ideation
- Severe liver disease

## 8. Follow-up

- Counselling
- Relapse prevention
- Liver function monitoring
