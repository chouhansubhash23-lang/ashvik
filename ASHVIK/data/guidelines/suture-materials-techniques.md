# Suture Materials and Techniques

> **Source:** ICMR STW Vol. 3 (2022); WHO; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Choose suture based on tissue, tension, and cosmetic need.
- Absorbable for deep tissue; non-absorbable for skin.
- Approximate edges without tension.
- Remove at the right time to avoid scarring.

## 2. Suture types

| Type | Examples | Use |
|---|---|---|
| Absorbable | Vicryl, catgut, Monocryl | Deep tissue, mucosa |
| Non-absorbable | Nylon, silk, polypropylene | Skin, fascia |
| Monofilament | Nylon, polypropylene | Skin (less infection) |
| Braided | Silk, Vicryl | Strong but more infection risk |

## 3. Sizes

| Site | Size |
|---|---|
| Face | 5-0/6-0 |
| Scalp | 3-0/4-0 |
| Limbs | 3-0/4-0 |
| Trunk | 2-0/3-0 |
| Fascia | 1-0/0 |

## 4. Diagnosis / Assessment

- Wound location, tension, contamination
- Neurovascular status
- Tetanus status
- Allergy to latex/materials

## 5. Treatment: techniques

| Technique | Use |
|---|---|
| Simple interrupted | Most wounds |
| Continuous | Long wounds, faster |
| Mattress | High tension |
| Subcuticular | Cosmetic |
| Figure-of-eight | Scalp/bleeding |

### Steps

1. Anaesthesia (lidocaine 1–2%)
2. Irrigate and debride
3. Approximate edges
4. Tie with appropriate tension
5. Dress and review

**Brand examples (illustrative):** Vicryl, Monocryl, Ethilon (nylon).

## 6. Supportive care

- Analgesia (paracetamol 500 mg)
- Keep wound dry
- Review in 48 h
- Suture removal: face 5 days, scalp 7–10 days, limbs 10–14 days

## 7. Drug interactions and cautions

- **Lidocaine:** max dose 3/7 mg/kg.
- **Antibiotics:** only if indicated.
- **Anticoagulants:** bleeding risk.
- **Infection:** remove sutures, drain.

## 8. Red flags — refer immediately

- Neurovascular deficit
- Tendon/joint involvement
- Infected wound
- Wound dehiscence
- Complex facial injury
