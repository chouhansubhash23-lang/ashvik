# Needlestick Injury Protocol

> **Source:** NACO; WHO; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Act immediately: wash, assess, PEP.
- HIV PEP within 72 hours (best < 2 h).
- Hepatitis B vaccine/immunoglobulin if non-immune.
- Report and document.

## 2. Immediate steps

1. Wash wound with soap and water.
2. Do not squeeze or suck.
3. Apply antiseptic.
4. Assess source and exposure.
5. Start PEP if indicated.

## 3. Diagnosis / Assessment

| Test | Use |
|---|---|
| HIV test (source/worker) | PEP decision |
| HBsAg, anti-HBs | Hepatitis B |
| HCV | Follow-up |
| Exposure type | Mucosal/percutaneous |

## 4. Treatment

| Infection | Prophylaxis |
|---|---|
| HIV | Tenofovir + lamivudine + dolutegravir x 28 days |
| Hepatitis B | Vaccine ± immunoglobulin |
| Hepatitis C | No PEP; monitor PCR |
| Tetanus | Booster if needed |

**Example:** TDF/FTC/DTG (NACO PEP regimen).

**Brand examples (illustrative):** Tenofovir; Lamivudine; Dolutegravir.

## 5. Supportive care

- Counselling
- Baseline/follow-up serology (0, 6 weeks, 3 months, 6 months)
- Report to infection control

## 6. Drug interactions and cautions

- **PEP:** nausea, hepatotoxicity; adherence.
- **HBIG:** allergy.
- **HCV:** no PEP; direct-acting antivirals if positive.
- **Paracetamol 500 mg** for pain.

## 7. Red flags — refer immediately

- High-risk exposure
- Source HIV positive with high viral load
- Mucosal exposure
- Pregnancy

## 8. Follow-up

- Complete PEP 28 days.
- Serology follow-up.
- Counselling.
