# Acute Kidney Injury (AKI)

> **Source:** ICMR STW Vol. 3 (2022); KDIGO; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-27
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- AKI = abrupt rise in creatinine or fall in urine output (KDIGO).
- Common causes: dehydration, sepsis, nephrotoxic drugs, obstruction, malaria/leptospirosis, snake bite.
- Most pre-renal AKI recovers with fluids and stopping nephrotoxins.
- **Hyperkalaemia, pulmonary oedema, and uremic encephalopathy are emergencies.**

## 2. Clinical features

- Reduced urine output (oliguria < 0.5 mL/kg/h) or anuria
- Swelling, breathlessness (fluid overload)
- Nausea, vomiting, confusion
- Fatigue, hiccups
- Features of cause: diarrhoea, sepsis, rash, jaundice

## 3. Diagnosis

| Test | Use |
|---|---|
| Serum creatinine | Baseline and trend |
| Urine output | Hourly monitoring if admitted |
| Urine dipstick | Protein, blood, casts |
| Electrolytes (K+, Na+) | Hyperkalaemia |
| Ultrasound KUB | Obstruction |
| CBC, malaria/dengue/leptospira tests | Cause |

## 4. Treatment

### 4.1 Immediate measures

| Measure | Detail |
|---|---|
| Stop nephrotoxins | NSAIDs, aminoglycosides, contrast, ACEi/ARB (temporarily) |
| Fluids | 0.9% saline if hypovolaemic; avoid overload |
| Urine output | Monitor; catheter if needed |
| Electrolytes | Treat hyperkalaemia: calcium gluconate, insulin-dextrose, salbutamol |
| Acidosis | Bicarbonate if severe |
| Referral | Dialysis if refractory hyperkalaemia, pulmonary oedema, uremia |

### 4.2 Cause-specific

| Cause | Management |
|---|---|
| Sepsis | Antibiotics, fluids, source control |
| Malaria/leptospirosis | Treat infection |
| Obstruction | Urgent urology referral |
| Rhabdomyolysis | Fluids, monitor CK |
| Contrast nephropathy | Hydration, avoid repeat contrast |

**No routine diuretics or dopamine** for AKI.

## 5. Supportive care

- Daily weight and fluid balance
- Adjust drug doses for renal function
- Nutrition support
- Avoid urinary catheter if not needed
- Monitor for infection

## 6. Drug interactions and cautions

- **NSAIDs:** worsen renal perfusion — avoid.
- **ACEi/ARB:** hold in acute illness; restart when stable.
- **Aminoglycosides:** nephrotoxic — avoid or monitor levels.
- **Contrast:** avoid unless essential; hydrate.
- **Metformin:** hold in AKI (lactic acidosis).
- **Potassium-sparing diuretics:** avoid in hyperkalaemia.

## 7. Red flags — refer immediately

- Anuria / severe oliguria
- K+ > 6.5 mmol/L or ECG changes
- Pulmonary oedema / breathlessness
- Uremic encephalopathy, seizures
- Severe acidosis
- Suspected obstruction
- AKI in pregnancy
- Rapidly rising creatinine

## 8. Follow-up

- Repeat creatinine/electrolytes in 24–48 h.
- Monitor urine output.
- Review medications.
- Nephrology follow-up after discharge.
