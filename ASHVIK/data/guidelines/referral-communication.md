# Referral Communication

> **Source:** NHP; NHM referral guidelines; WHO
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- A good referral saves time and lives.
- Use a structured note: reason, findings, treatment given, what is needed.
- Stabilise before transfer.
- Communicate directly when possible.

## 2. Diagnosis / Assessment

- Determine need for referral (beyond PHC capacity).
- Assess stability for transport.
- Identify receiving facility.
- Prepare documents.

## 3. Treatment: referral note

| Element | Content |
|---|---|
| Patient ID | Name, age, sex, ID |
| Reason | Diagnosis/question |
| History | Key symptoms, duration |
| Findings | Vitals, exam |
| Treatment given | Drugs/doses (e.g., aspirin 300 mg) |
| Investigations | Results |
| Request | What is needed |
| Contact | Referring doctor/phone |

- Send copies of records.
- Use 108 ambulance when available.
- Call ahead for emergencies.

## 4. Drug interactions and cautions

- **Dose:** not applicable (non-drug topic).
- **Aspirin 300 mg** example of documenting pre-referral treatment.
- **Unstable patient:** stabilise first.
- **Confidentiality:** share only needed information.

## 5. Supportive care

- Explain to patient/family.
- Arrange transport.
- Provide follow-up plan.

## 6. Red flags

- Unstable patient transported without stabilization
- No referral note
- Wrong facility
- Missing records
- No communication

## 7. Follow-up

- Confirm arrival.
- Obtain feedback.
- Document outcome.
