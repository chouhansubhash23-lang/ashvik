# ECG Interpretation Basics

> **Source:** ICMR STW Vol. 3 (2022); AHA; WHO
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- ECG is essential for chest pain, palpitations, syncope, and drug overdose.
- Use a systematic approach: rate, rhythm, axis, intervals, ST/T.
- **STEMI is a time-critical finding.**
- Always interpret in clinical context.

## 2. Systematic reading

| Step | Check |
|---|---|
| Rate | 300 / number of large squares (regular) |
| Rhythm | P waves, PR relationship, regularity |
| Axis | I and aVF |
| Intervals | PR 120–200 ms, QRS < 120 ms, QT |
| Hypertrophy | LVH/RVH criteria |
| Ischemia/infarction | ST elevation/depression, T inversion, Q waves |

## 3. Common patterns

| Pattern | Features |
|---|---|
| STEMI | ST elevation in contiguous leads |
| NSTEMI/ischemia | ST depression, T inversion |
| AF | Irregularly irregular, absent P waves |
| SVT | Narrow complex, regular, fast |
| VT | Wide complex, regular |
| Heart block | Prolonged PR, dropped beats |
| Hyperkalaemia | Tall tented T waves, wide QRS |
| Hypokalaemia | U waves, flat T |

## 4. Diagnosis / Assessment

- 12-lead ECG within 10 min of chest pain
- Compare with old ECG
- Repeat if symptoms evolve
- Check electrolytes

## 5. Treatment implications

| Finding | Action |
|---|---|
| STEMI | Aspirin 300 mg, refer for PCI/thrombolysis |
| VT with pulse | Antiarrhythmic/cardioversion |
| VT pulseless | CPR/defibrillation |
| Hyperkalaemia | Calcium gluconate, insulin-dextrose |
| Bradycardia with symptoms | Atropine 0.5 mg IV |

**Brand examples (illustrative):** Aspirin — Ecosprin; Atropine — Atropine.

## 6. Drug interactions and cautions

- Antiarrhythmics can cause proarrhythmia; monitor QT.
- Electrolyte abnormalities alter ECG — correct before attributing to drugs.
- Digoxin toxicity causes arrhythmias.

## 7. Supportive care

- Oxygen if hypoxic
- IV access
- Monitor
- Treat cause

## 8. Red flags — refer immediately

- STEMI
- VT/VF
- Complete heart block
- Severe bradycardia with hypotension
- Hyperkalaemia with wide QRS

## 9. Follow-up

- Repeat ECG
- Cardiology referral
- Electrolyte correction
