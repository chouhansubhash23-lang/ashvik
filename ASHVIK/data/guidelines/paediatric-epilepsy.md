# Paediatric Epilepsy

> **Source:** ICMR; ILAE; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Epilepsy = recurrent unprovoked seizures.
- First seizure needs evaluation.
- **Status epilepticus is an emergency.**
- Choose AED by seizure type and age.

## 2. Clinical features

- Generalised tonic-clonic
- Absence (staring)
- Focal seizures
- Myoclonic jerks
- Developmental regression (some syndromes)

## 3. Diagnosis / Assessment

| Test | Use |
|---|---|
| Witness history | Seizure type |
| EEG | Support diagnosis |
| MRI/CT | Structural cause |
| Glucose/electrolytes | Reversible causes |
| Developmental assessment | Syndrome |

## 4. Treatment

| Seizure type | AED |
|---|---|
| Generalised | Valproate (avoid in girls), levetiracetam |
| Focal | Carbamazepine, levetiracetam, oxcarbazepine |
| Absence | Ethosuximide, valproate |
| Status | Lorazepam 0.1 mg/kg, then phenytoin 20 mg/kg |

**Brand examples (illustrative):** Valparin; Levipil; Tegretol; Eptoin.

- Folic acid 5 mg for girls on valproate.
- Avoid valproate in women of childbearing age.

## 5. Supportive care

- Safety advice
- School support
- Sleep hygiene
- Adherence

## 6. Drug interactions and cautions

- **Valproate:** hepatotoxicity, pancreatitis, teratogenic.
- **Carbamazepine:** enzyme inducer; rash.
- **Phenytoin:** narrow index; gum hypertrophy.
- **Levetiracetam:** behavioural changes.

## 7. Red flags — refer immediately

- Status epilepticus
- First seizure
- Focal deficit
- Developmental regression
- Seizures in neonate
- Head injury

## 8. Follow-up

- Review every 1–3 months.
- AED levels if available.
- Developmental assessment.
