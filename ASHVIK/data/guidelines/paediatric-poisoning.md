# Paediatric Poisoning

> **Source:** NCDC; WHO; NHP
> **Evidence:** `../../evidence/sources.md`
> **Last verified:** 2026-10-28
> **Status:** Draft — clinician review required
> **Setting:** Rural OPD / PHC (India)

## 1. Quick facts

- Common: kerosene, pesticides, iron, paracetamol, rat poison, household cleaners.
- **Do not induce vomiting.**
- Stabilise ABCDE and refer.
- Keep the container for identification.

## 2. Clinical features

| Agent | Features |
|---|---|
| Kerosene | Cough, breathlessness (aspiration) |
| OP pesticide | SLUDGE, miosis, bradycardia |
| Iron | Vomiting, GI bleed, shock |
| Paracetamol | Late hepatotoxicity |
| Rat poison | Bleeding |
| Corrosive | Oral burns, drooling |

## 3. Diagnosis / Assessment

- Agent, amount, time
- Weight
- Vitals, SpO2
- Glucose
- ECG, electrolytes

## 4. Treatment

| Agent | Treatment |
|---|---|
| OP | Atropine 0.02 mg/kg IV, repeat; pralidoxime |
| Paracetamol | N-acetylcysteine 150 mg/kg IV |
| Iron | Desferrioxamine 15 mg/kg/h |
| Kerosene | No lavage; oxygen; refer |
| Corrosive | No lavage; refer |

**Activated charcoal 1 g/kg** if within 1 h and airway protected (not corrosives/hydrocarbons).

**Brand examples (illustrative):** Atropine; Pralidoxime; NAC.

## 5. Supportive care

- Oxygen
- IV fluids
- Monitor
- Psychological support

## 6. Drug interactions and cautions

- **Atropine:** tachycardia; titrate.
- **NAC:** nausea, bronchospasm.
- **Activated charcoal:** aspiration risk.
- **Never induce vomiting.**

## 7. Red flags — refer immediately

- Respiratory distress
- Altered consciousness
- Seizures
- Shock
- Corrosive ingestion
- Intentional overdose

## 8. Follow-up

- Psychiatric assessment if intentional.
- Counselling on safe storage.
- LFT/renal follow-up.
