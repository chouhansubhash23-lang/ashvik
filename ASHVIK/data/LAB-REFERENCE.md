# ASHVIK — Basic Lab Reference Library

Collected: **2026-10-29** · Report items: **109** (86 quantitative + 19 qualitative/serology + 4 Widal titres) · Categories: **14**

## Why this exists

ASHVIK reads uploaded lab reports offline, extracts common values, flags them against a reference interval, and uses the values as additional evidence in differential diagnosis. This record documents the reference table embedded in the app.

## Source and scope

Typical adult reference intervals used by Indian NABL-accredited laboratories; cross-checked with Focus Diagnostics' Normal Lab Values & Reference Ranges (January 2025).

Supporting standards:

- ADA diabetes diagnostic cut-offs (fasting, post-load and HbA1c).
- WHO/ICMR-style adult haemoglobin and nutritional anaemia cut-offs.
- Standard clinical cut-offs for serology, coagulation, cardiac and urine routine tests.

Primary reference chart: https://focusdiagnostics.in/normal-lab-values

> **Caveat:** Reference intervals are method- and population-dependent. Paediatric, pregnancy, critical-care and some analyser-specific ranges differ. Always use the interval printed on the patient's own report; the doctor remains the final approver.

## How the app uses it

- OCR values are parsed from printed English reports; Widal titres are parsed separately.
- Each numeric value is flagged Low/High using the table above unless the report's own range is available.
- The latest value per test across reports is auto-loaded into Quick Differential and ASHVIK Doctor.
- Abnormal values become **Report-based findings**; the doctor must verify every OCR value and interpretation.
- Urine dipstick results (nitrite, leukocyte esterase, protein, blood, glucose) are used as supporting evidence, not as a standalone diagnosis.
