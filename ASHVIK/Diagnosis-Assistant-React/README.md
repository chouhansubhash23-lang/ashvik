# Diagnosis Assistant (React)

React-based clinical decision support frontend (CDN + Babel, single file, no build step).

## How to use
1. Open `index.html` in a modern browser (internet required once to load React CDN).
2. Select a patient, tick symptoms, enter vitals and doctor's impression.
3. Click **Generate Diagnosis** for differential diagnosis, red flags, recommended tests.
4. Save result to patient history; manage test reports with file uploads.

## Notes
- Data stored in browser localStorage (shared key with ASHVIK).
- Professional medical UI theme (teal/white, Inter font).
- No backend required.
